# Caesar Cipher

A Python project that encrypts and decrypts text by 
shifting letters through the alphabet.

## What it does
You give it a text and a number (the shift), and it 
moves each letter that many positions forward to encrypt, 
or backward to decrypt.

## How to use
encrypt("Hello", 3)  → "Khoor"
decrypt("Khoor", 3)  → "Hello"

## Built with
Python 3
